# 绿盾助手

> **注意：本仓库原名为 `lvdun-vcalc`，原为“绿盾V算 —— 工况/标况/参比体积换算小工具（Android 离线版 + Web 版）”。现已重新定位为“绿盾助手 —— 公共卫生检测工作单文件工具集”，原绿盾V算代码不再维护。**

湖南绿盾卫士检测技术有限公司内部使用的学校卫生综合评价单文件工具。

- 工具入口：`index.html`（自包含单文件，无外链）
- 配套文档：见公司内部 `Q报告` 文件夹
- 部署方式：GitHub Pages（本仓库 `yunshenbuzhichu0719/lvdun-vcalc` 的 main 分支根目录）

## 功能一览

| 模块 | 说明 |
| --- | --- |
| ① 教室人均面积 | 按 GB/T 18205-2012 4.2.3.3 |
| ② 窗地面积比 | 按 GB/T 5699-2025，光气候区 Ⅳ类默认 1.10:5 |
| ③ 课桌面照度及均匀度 | 按 GB/T 5700-2023 6.1.1、表 D.9（≤2.0×2.0 m 网格） |
| ④ 黑板照度及均匀度 | 按 GB/T 5700-2023 6.1.1、表 D.9（≤0.5×0.5 m 网格） |
| ⑤ 建议布点图 | 同比例尺横向纵向、含尺寸标注与自适应比例尺 |
| ⑥ 原始记录导出 | LDWS-JS01-013（1）Word 模板，非破坏性注入 |

## 限值依据

- **GB 50099-2011** 《中小学校设计规范》
- **GB 7793-2025** 《中小学校教室采光和照明卫生标准》（2025-10-05 发布，2026-11-01 实施）

## 桌面三处副本

为方便局域网同事访问，本工具同时存在三处本地副本、文件**字节级一致**：

1. `C:\Users\A\Desktop\lvdun-helper.html`
2. `C:\Users\A\Desktop\vcalc\index.html`
3. `C:\Users\A\Desktop\lvdun-helper-site\index.html`

修改任意一份后，另两份可用生成脚本一键同步（详见 `lvdun-helper-html` 技能手册）。
